# ShowRoom Doctor Z Inc. website (static)

Single-page, mobile-first, accessible landing site for ShowRoom Doctor Z Inc., Clovis, CA. Plain HTML and CSS, no build step or tracking scripts.

- `index.html` is generated by `build.py` (edit facts there, then run `python3 build.py`).
- Includes meta and Open Graph tags, schema.org LocalBusiness JSON-LD, `sitemap.xml`, `robots.txt`, favicons.
- Canonical URL is https://showroomdrz.com/ .

## Facts source
Capability statement (Nov 2026), SAM.gov registration data, Cal eProcure, CA DGS, and the previous Shopify store content. Miracle Spritz makes no disinfectant, pesticide or germ-kill claims.

## Hosting
GitHub Pages (free): Settings > Pages > Deploy from branch `main` / root.

To use showroomdrz.com: (1) in Settings > Pages > Custom domain enter `showroomdrz.com` and Save (this adds a `CNAME` file); do this right before the DNS switch, because after it the github.io address redirects to showroomdrz.com. (2) Change DNS at the DNS host:
- Apex `@` A records: 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153
- Apex `@` AAAA records (optional): 2606:50c0:8000::153, 2606:50c0:8001::153, 2606:50c0:8002::153, 2606:50c0:8003::153
- `www` CNAME -> `jz-ctrl.github.io`
- Remove the existing Shopify records for the apex and www. Keep MX and TXT (email) records.
(3) Tick Enforce HTTPS once it becomes available (up to 24 hours).
